# GATE command-center positioning

The public offering is **GATE — Governed AI Transformation for Enterprises™**, presented as **Your AI Transformation Command Center**. It replaces the earlier Enterprise AI Transformation Framework and duplicate prototype presentation.

> GATE brings AI projects, approved knowledge and accountable decisions into one workspace. Give leadership a clearer view of what to advance, what needs intervention and what should pause.

The page leads with the portfolio decision, explains implemented capabilities, gives CFO/CIO/CEO/CTO/Legal review perspectives, links to the current application, simulation and user manual, and distinguishes demonstrable pilot behavior from enterprise acceptance work. It avoids unsupported returns, certifications, customer endorsements, turnkey integration promises and claims of continuous automatic enterprise audit.

The current application is a private owner preview at `https://gate-enterprise.praba.chatgpt.site`; a link does not grant access. Customer identity/deployment, `/gate` hosting and commercial billing remain separate work. No Site access setting changes as part of the public marketing release.

Canonical public pages retain the established `/en/apps/ai-transformation-command-center` and `/ja/apps/ai-transformation-command-center` URLs. Old framework and demo paths redirect there. The homepage and resource index now use GATE consistently.

Copy lives in `apps/web/lib/gate-pitch.ts` and synchronized Markdown under `content/apps/ai-transformation-command-center/`. Public content API reads use this reviewed Markdown, so historical Firestore descriptions cannot replace the current pitch. Japanese copy retains `review_required` metadata.
