## Shared foundation

| Colour | Value | Shared role |
| --- | --- | --- |
| Cardinal | `#8C1515` | Personal identity and primary emphasis |
| Deep cardinal | `#641C19` | Strong editorial surfaces |
| Bridge orange | `#B83B27` | Restrained accent |
| Sandstone | `#D8C3A5` | Architectural warmth and framing |
| Ivory | `#F6F3EC` | Calm page canvas |
| Warm paper | `#FFFCF7` | Reading surfaces |
| Charcoal | `#2E2D29` | Primary text |
| Coastal slate | `#4D6471` | Analytical application emphasis |
| Deep coastal slate | `#263B45` | Navigation and venture surfaces |

Use the actual activity's theme tokens rather than copying light colours into dark mode. Preserve visible keyboard focus, readable labels, natural Japanese wrapping, reduced-motion behavior, and layouts that fit desktop/tablet/phone. Status colours communicate meaning independently of decorative accents; pair them with labels or symbols.

Photographs should remain authentic and credited. Owner-selected education images are recorded in [education provenance](../EDUCATION_SLIDESHOW.md). The supplied Stanford GSB wordmark belongs only in the documented profile affiliation treatment; it does not replace the personal or application marks.

GATE was a typography reference for the English profile, not redesigned in this session. No new brand is declared here for GATE, HealthKit Sync, Innuir or AAGNAA. Venture panels inherit the website presentation; this does not establish their corporate brand systems.
